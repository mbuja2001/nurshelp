# Clinical Care Mode & EHR Integration Implementation Plan

## Overview
With staff roles, scheduling, and bed allocation already working, the next layer is **Clinical Care Mode**—where nurses transition from "Air Traffic Controller" (Triage) to "Bedside Pilot" (Treatment). This implementation focuses on:

1. **Context-Aware Dashboard**: Single UI that transforms based on staff mode
2. **Clinical Encounter Record (Object 3/5)**: Captures treatment data separate from triage
3. **Escalation Alert Logic**: Live P2P physician requests with response tracking
4. **Finalise & Sync**: EHR bundle packaging for downstream integration

---

## 1. THE 5-OBJECT LONGITUDINAL RECORD ARCHITECTURE

### Current Objects (Already Exist)
```
Object 1: AI Suggested Report
  - Generated by RAG engine at check-in
  - Static snapshot of AI diagnostic suggestions
  - Used by nurses/physicians for context

Object 2: Nurse Triage Report (SATS)
  - Quick vital assessment (vitals, SATS score)
  - Triage level assignment (GREEN/YELLOW/ORANGE/RED)
  - Duration: 5-10 minutes per patient
  - Triggers: Dispatch to ward or fast-track

Object 4: Physician Feedback Report
  - Final diagnosis and clinical judgment
  - Review of triage accuracy
  - Treatment recommendations
  - Discharge/admit decision

Object 5: Audit Bundle
  - Metadata linking all objects
  - Who, When, Where, Why for each action
  - Legal/medicolegal tracking
```

### New Object to Build
```
Object 3: Clinical Encounter Record ⭐ NEW
  - Treatment phase data (separate from triage)
  - Vitals trends over time
  - Procedures/interventions logged
  - Escalation requests ("Request Physician")
  - Treatment duration timestamp
  - Consumables used (links to BOM)
  - Dynamic (written to during care phase)
```

```javascript
// Location: src/context/StaffStateProvider.jsx

import React, { createContext, useState, useEffect } from 'react';

export const StaffStateContext = createContext();

export const StaffStateProvider = ({ children }) => {
  const [mode, setMode] = useState('TRIAGE');  // 'TRIAGE' or 'CLINICAL_CARE'
  const [activePatient, setActivePatient] = useState(null);
  const [clinicalEncounter, setClinicalEncounter] = useState(null);
  
  const switchToClinicaIlCare = async (patient, encounterData) => {
    setActivePatient(patient);
    setClinicalEncounter(encounterData);
    setMode('CLINICAL_CARE');
    
    // Log audit trail
    logAuditEvent('MODE_SWITCH', 'TRIAGE_TO_CLINICAL_CARE', { patientId: patient._id });
  };
  
  const switchToTriage = () => {
    setMode('TRIAGE');
    setActivePatient(null);
    setClinicalEncounter(null);
  };
  
  return (
    <StaffStateContext.Provider
      value={{
        mode,
        activePatient,
        clinicalEncounter,
        switchToClinicaIlCare,
        switchToTriage,
      }}
    >
      {children}
    </StaffStateContext.Provider>
  );
};
```

```javascript
          procedureName,
          procedureType: type,
          performedAt: new Date(),
        }),

      onProcedureLog({ name: procedureName, type });
    }
  };
  
  return (

      {SA_PROCEDURES.map(proc => (
        <label key={proc.name} className="procedure-item">
          <input 
            type="checkbox"
```

### 5.2 WebSocket / Mesh Service for Live Alerts

```javascript
// Location: src/services/EscalationService.js

class EscalationService {
  constructor() {
    this.socket = null;
    this.listeners = {};
  }
  
  connect() {
    // Connect to local WebSocket (or mesh network if offline)
    this.socket = new WebSocket('ws://localhost:5001/escalations');
    
    this.socket.onmessage = (event) => {
      const esacalationAlert = JSON.parse(event.data);
      this.notifyListeners('ESCALATION_ALERT', esacalationAlert);
    };
  }
  
  sendEscalation(payload) {
    this.socket.send(JSON.stringify({
      type: 'ESCALATION_REQUEST',
      ...payload,
    }));
  }
  
  subscribe(event, callback) {
    if (!this.listeners[event]) {
      this.listeners[event] = [];
    }
    this.listeners[event].push(callback);
  }
  
  notifyListeners(event, data) {
    if (this.listeners[event]) {
      this.listeners[event].forEach(callback => callback(data));
    }
  }
}

export const escalationService = new EscalationService();
```

### 6.1 EHR Bundle Factory

```javascript
// Location: src/services/EHRBundleFactory.js

class EHRBundleFactory {
  
  async createBundle(patientId, encounterId) {
    // Fetch all 4 objects
    const aiSuggestion = await this.getObject1(encounterId);
    const nurseTriage = await this.getObject2(encounterId);
    const clinicalEncounter = await this.getObject3(encounterId);
    const physicianFeedback = await this.getObject4(encounterId);
    
    // Integrity check
    this.validateObjectLinkage(aiSuggestion, nurseTriage, clinicalEncounter);
    
    // Run discrepancy analysis
    const discrepancyScore = this.analyzeDiscrepancies(
      aiSuggestion,
      nurseTriage,
      physicianFeedback
    );
    
    // Build HL7 FHIR-compliant bundle
    const bundle = {
      resourceType: "Bundle",
      type: "transaction",
      
      identifier: {
        system: "urn:nhd:identifiers:encounter",
        value: encounterId,
      },
      
      // Header
      header: {
        patientId,
        facilityId: nurseTriage.hospitalId,
        staffIds: [
          nurseTriage.triageNurseId,
          clinicalEncounter.assignedNurseId,
          physicianFeedback?.physicianId,
        ],
        timestamp: new Date(),
      },
      
      // Segment 1: Triage Phase
      segment_triage: {
        object_1_ai_suggestion: aiSuggestion,
        object_2_nurse_triage: nurseTriage,
      },
      
      // Segment 2: Clinical Encounter (Treatment Phase)
      segment_encounter: {
        object_3_clinical_encounter: clinicalEncounter,
        vitals_trends: clinicalEncounter.vitalsHistory,
        procedures: clinicalEncounter.procedureLog,
        escalations: clinicalEncounter.escalationRequests,
      },
      
      // Segment 3: Physician Review
      segment_feedback: {
        object_4_physician_feedback: physicianFeedback,
      },
      
      // Segment 4: Audit Trail
      segment_audit: {
        object_5_audit_bundle: this.buildAuditBundle(
          aiSuggestion,
          nurseTriage,
          clinicalEncounter,
          physicianFeedback
        ),
      },
      
      // Metadata
      discrepancyScore,
      discrepancyTags: this.generateDiscrepancyTags(discrepancyScore),
    };
    
    return bundle;
  }
  
  analyzeDiscrepancies(aiSuggestion, nurseTriage, physicianFeedback) {
    const discrepancies = {
      triage_accuracy: 0,
      ai_accuracy: 0,
      treatment_alignment: 0,
    };
    
    // Did physician change triage level?
    if (nurseTriage.triageLevel !== physicianFeedback.finalTriageLevel) {
      discrepancies.triage_accuracy = 1;  // Flag
    }
    
    // Did physician agree with AI suggestion?
    if (physicianFeedback.diagnosis !== aiSuggestion.suggestedDiagnosis) {
      discrepancies.ai_accuracy = 1;
    }
    
    // Did treatment match assessment?
    if (this.assessTreatmentAlignment(physicianFeedback)) {
      discrepancies.treatment_alignment = 0.5;
    }
    
    // Return composite score (0-100)
    const score = (discrepancies.triage_accuracy * 30 +
                   discrepancies.ai_accuracy * 30 +
                   discrepancies.treatment_alignment * 40);
    
    return Math.round(score);
  }
  
  buildAuditBundle(obj1, obj2, obj3, obj4) {
    return {
      encounter_timeline: [
        {
          timestamp: obj2.triageTime,
          event: "PATIENT_TRIAGED",
          actor: obj2.triageNurseId,
          object: "Object 2",
        },
        {
          timestamp: obj3.assignmentTime,
          event: "CLINICAL_CARE_STARTED",
          actor: obj3.assignedNurseId,
          object: "Object 3",
        },
        {
          timestamp: obj3.finalizeTime,
          event: "ENCOUNTER_FINALIZED",
          actor: obj3.assignedNurseId,
          object: "Object 3",
        },
        {
          timestamp: obj4.reviewTime,
          event: "PHYSICIAN_REVIEW_COMPLETE",
          actor: obj4.physicianId,
          object: "Object 4",
        },
      ],
      
      treatment_duration: obj3.finalizeTime - obj3.assignmentTime,
      response_latencies: obj3.escalationRequests.map(e => ({
        requestAt: e.requestedAt,
        responseAt: e.acknowledgedAt,
        latencyMinutes: (e.acknowledgedAt - e.requestedAt) / (1000 * 60),
      })),
    };
  }
}

export const ehrBundleFactory = new EHRBundleFactory();
```

```javascript
export const FinalizeSyncControls = ({ clinicalEncounter, onFinalizeClick }) => {
  const [isSyncing, setIsSyncing] = useState(false);
  const [syncStatus, setSyncStatus] = useState(null);
  
  const handleFinalizeAndSync = async () => {
    setIsSyncing(true);
    
    try {
      // 1. Mark Clinical Encounter as FINALIZED
      await fetch(`/api/encounters/${clinicalEncounter._id}/finalize`, {
        method: 'POST',
        body: JSON.stringify({
          finalizeTime: new Date(),
          finalizedBy: nurseId,
        }),
      });
      
      // 2. Create EHR bundle
      const bundle = await ehrBundleFactory.createBundle(
        clinicalEncounter.patientId,
        clinicalEncounter._id
      );
      
      // 3. Queue for sync (handles offline scenario)
      await enqueueSyncBundle(bundle);
      
      // 4. Auto-trigger next actions
      // - Mark bed as CLEANING
      // - Clear from nurse's active list
      // - Start bed turnaround timer
      
      setSyncStatus('SYNCED');
      
      // Close encounter
      setTimeout(() => {
        switchToTriage();
        resetActivePatient();
      }, 2000);
      
    } catch (error) {
      setSyncStatus('ERROR');
      console.error('Finalization error:', error);
    } finally {
      setIsSyncing(false);
    }
  };
  
  return (
    <div className="finalize-sync-controls">
      <button 
        onClick={onFinalizeClick}
        className="btn-large btn-primary"
        disabled={isSyncing}
      >
        🎯 Finalise & Sync
      </button>
      
      {syncStatus === 'SYNCED' && (
        <div className="sync-confirmation">
          ✅ Encounter finalized and queued for EHR sync
        </div>
      )}
    </div>
  );
};
```

## 9. KEY METRICS THAT NOW BECOME TRACKABLE

```
With this architecture, you unlock:

1. Treatment Duration = Finalize Time - Assignment Time
   └─ KPI for hospital efficiency

2. Response Latency = Physician Acknowledge Time - Escalation Request Time
   └─ KPI for physician responsiveness

3. Triage Accuracy = (Physician Final Diagnosis == Nurse Initial Triage)
   └─ Quality metric for triage team

4. Escalation Rate = Count of "Request Physician" clicks per 100 patients
   └─ Staff competency indicator

5. Discrepancy Score = AI Suggestion vs Physician Decision vs Nurse Triage
   └─ System accuracy metric

6. Self-Correction Events = Nurse hits "Re-Triage / Upgrade"
   └─ Positive: Nurse catches their own mistake

7. Resource Waste = Consumables Used vs Physician Assessment of Need
   └─ Cost containment metric (public & private billing)
```

## 10. SUMMARY: Why This Architecture Wins

✅ **Separates concerns**: Triage (Object 2) ≠ Treatment (Object 3)
✅ **Unlocks EHR integration**: Clean, chronological data for downstream systems
✅ **Enables analytics**: Every click is a timestamped data point
✅ **Supports offline**: WebSocket + mesh for low-connectivity settings
✅ **Scales staff roles**: Same UI, different modes based on state
✅ **Medicolegal protection**: Full audit trail from triage → treatment → physician review
✅ **Identifies waste**: AI vs Nurse vs Physician discrepancies surface inefficiencies
