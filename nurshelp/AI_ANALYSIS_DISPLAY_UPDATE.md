## Complete Display Structure (Already Implemented)

The PatientReport.jsx component now properly displays all fields from the aiTriageReport object:

### Top-Level Display
- **Priority Code** - RED/ORANGE/YELLOW/GREEN badge with target time
- **AI Triage Summary** - Clinical overview from `clinical_summary` or `pathophysiology`

### Collapsible Clinical Analysis Sections
1. **🔬 Pathophysiology & Organ Systems** - System-by-system analysis from `pathophysiology`
2. **✓ Clinical Summary** - Brief clinical overview from `clinical_summary`
3. **⚠️ Severity Assessment** - Compensating/Decompensating status from `severity_assessment`
4. **🎯 Clinical Discriminators** - Key findings that support the ESI level from `clinical_discriminators`
5. **📊 Differential Diagnoses** - List of working diagnoses with confidence scores from `differential_diagnoses`
6. **✅ Life Threats Ruled Out** - Confirmed negative diagnoses from `life_threats_excluded`
7. **👨‍⚕️ Specialist Consultation** - Recommended specialist departments from `recommended_specialists`
8. **🚨 STAT Actions (Immediate)** - Critical interventions from `immediate_actions`
9. **🔬 Diagnostic Investigations** - Required lab/imaging from `diagnostic_workup`
10. **💊 Treatment Recommendations** - Medication/therapy suggestions from `recommendations`
11. **⭐ Pathognomonic Findings** - Uniquely diagnostic markers from `pathognomonic_markers`

### Data Extraction Pattern (Lines 379-410)
```jsx
// Clinical Summary - priority order fallback chain
let aiSummaryRaw = triageData?.aiTriageReport?.clinical_summary ?? 
                   triageData?.clinical_summary ?? 
                   triageData?.aiTriageReport?.pathophysiology ?? 
                   triageData?.pathophysiology ?? 
                   triageData?.ai_summary ?? 
                   triageData?.summary ?? "";

// Clinical Discriminators - pulls from aiTriageReport array
const discriminatorsList = Array.isArray(triageData?.aiTriageReport?.clinical_discriminators) 
  ? triageData.aiTriageReport.clinical_discriminators
  : Array.isArray(triageData?.SATS_reasoning?.discriminators_readable) 
  ? triageData.SATS_reasoning.discriminators_readable
  : [];

// Specialty - from aiTriageReport with fallback
const assignedSpecialty = triageData?.aiTriageReport?.specialty ?? 
                          triageData?.aiTriageReport?.recommended_specialty ?? 
                          triageData?.assigned_specialty ?? "";
```

## Backend Data Flow

### ESI_Engine.py GGUF Inference
**File:** `backend/ML/ESI_Engine.py`
- **Endpoint:** POST `/api/llm-triage`
- **Model:** MedGemma 4B (Q4_K_M quantized)
- **Context Window:** 256 tokens (adaptive based on system RAM)
- **Output:** JSON with aiTriageReport structure

### aiTriageReport JSON Structure
```json
{
  "esi_level": 1-5,
  "priority_code": "RED|ORANGE|YELLOW|GREEN",
  "specialty": "Cardiology|Trauma|etc",
  "clinical_discriminators": ["discriminator1", "discriminator2"],
  "differential_diagnoses": [
    {"dx": "diagnosis", "confidence": 0.95},
    {"dx": "diagnosis", "confidence": 0.85}
  ],
  "pathophysiology": "Detailed organ system analysis...",
  "clinical_summary": "Brief overview...",
  "severity_assessment": "Compensating|Decompensating",
  "life_threats_excluded": ["threat1", "threat2"],
  "recommended_specialists": ["specialist1", "specialist2"],
  "clinical_actions": ["action1", "action2"],
  "immediate_actions": ["critical action1"],
  "diagnostic_workup": ["test1", "test2"],
  "recommendations": ["recommendation1"],
  "pathognomonic_markers": ["marker1"]
}
```
